# Step 8: Buffer or another tool (optional)

**Goal:** finished posts land in the user's scheduling tool as drafts. Stopping before this step is completely fine. They can download the image and post it themselves.

## What you do

1. Ask which tool they use. If they have none, Buffer is a simple start: its free plan holds 10 drafts.
2. Check what is available in the connector settings of the Claude app and in the tool's current official docs. Don't rely on memory. Give numbered click steps. Ask before anything that costs money.
3. Test with one finished post, as a **draft**, never scheduled or published. The user checks it in the tool.
4. Only after a working test, add to `brand/niche.md` the line: "After the user says 'I like it', send the post to <tool> as a draft." The morning run itself still sends nothing.

## Done when

- a test draft arrived and the user saw it, or the user decided against it (marked "skipped" in the log)

**STOP:** tick or mark skipped.
