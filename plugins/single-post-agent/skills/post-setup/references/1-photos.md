# Step 1: Photos

**Goal:** real photos of the person, described so the agent can pick the right one. Photos stay on this computer.

## What the user does

Drops at least 3 or 4 of their own photos into `my-photos/`. Open the folder for them (on a Mac: `open my-photos`), so they can drag the photos into the window. More is better: at the laptop, thinking, laughing. Calm backgrounds work best. More can be added any time.

## What you do

1. Look at every photo. If you can't read a format such as HEIC, convert a copy to JPG and say so.
2. Write `my-photos/INDEX.md`: one line per photo with the file name, what's in it, the mood, which topics it fits, where the head sits, and whether the top or the bottom can hold text without covering the head, hair, hands or anything important.
3. Real photos are the default. If a photo is AI-generated, tell the user it has to be labelled as AI-generated.
4. Say if a photo won't work well (dark, busy, face cut off).

## Done when

- `my-photos/INDEX.md` lists at least 3 usable photos

**STOP:** tick, ask about step 2.
