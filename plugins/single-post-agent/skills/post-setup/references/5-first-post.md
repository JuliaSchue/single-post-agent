# Step 5: First post by hand

**Goal:** one full post works before anything runs on its own.

## What you do

1. Follow the `post-daily` skill, but skip the scan. Ask the user for a topic they want to post about, or suggest three from `brand/niche.md`. Write `topics/<today>.md` with this topic and note "no scan, first post by hand". Reserve topics and the Apify cost start with the morning run in step 7.
2. Show the image and the caption from `posts/<today>_<slug>/`.
3. Take feedback, write it to `brand/feedback.md`, and change the post until the user likes it.

## Done when

- the user approved one post in words

**STOP:** tick, ask about step 6.
